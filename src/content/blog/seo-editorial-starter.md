## Propósito de esta entrada

Esta pieza existe únicamente para comprobar la colección editorial, el layout de artículo y la salida SEO durante el desarrollo. Debe sustituirse o eliminarse antes de publicar un proyecto real.

## Contenido mantenible

El cuerpo se edita como Markdown y puede incluir listas, enlaces, citas, imágenes accesibles y tablas sencillas sin trasladar esa estructura al componente de página.

- El frontmatter concentra los metadatos.
- El layout concentra la presentación.
- El helper de publicación controla los borradores.

> El contenido de demostración no debe confundirse con contenido final del proyecto.

| Elemento | Responsabilidad |
| --- | --- |
| Frontmatter | Datos editoriales y SEO |
| Markdown | Contenido de lectura |
| Layout | Semántica y presentación |
